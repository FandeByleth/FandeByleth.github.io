¿Que es un Sistema Operativo?

Es el Software fundamental que gestiona el hardware, los recursos y las aplicaciones de
computadoras y dispositivos moviles. Actua como intermediario entre el usuario y la maquina, controlando
funciones esenciales como la memoria, el procesador (CPU), los archivos y la seguridad.


EJEMPLOS DE SISTEMAS OPERATIVOS:
WINDOWS, LINUX, MACOS, MS-DOS, ANDROID, IOS, WINDOWS PHONE.
