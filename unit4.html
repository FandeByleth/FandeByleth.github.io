UNIDAD 4. ADMINISTRACION DE ENTRADA/SALIDA

4.1 DISPOSITIVOS Y MANEJADORES DE DISPOSITIVOS

Los dispositivos son los componentes de hardware (periféricos) y el software que componen una computadora, mientras que los manejadores de dispositivos (drivers) son los programas intermedios que permiten al sistema operativo comunicarse directamente con estos equipos físicos.

Dispositivos (Periféricos)

Son todos los aparatos auxiliares e independientes que se conectan a la unidad central de procesamiento para enviar, recibir o almacenar información. Se dividen principalmente en tres categorías:

De entrada: Permiten al usuario ingresar datos y comandos al sistema (ej. teclado, ratón, micrófono, escáner).

De salida: Muestran los resultados procesados por la computadora hacia el exterior (ej. monitor, altavoces, impresora).

De almacenamiento: Guardan datos e información para su uso posterior (ej. discos duros, memorias USB, unidades de estado sólido).

A su vez, a nivel lógico del sistema operativo, estos se clasifican en:

Dispositivos de bloque: Almacenan información en bloques de tamaño fijo y permiten leer o escribir de forma independiente (ej. discos duros).

Dispositivos de carácter: Transfieren información como un flujo continuo de datos sin estructura de bloques (ej. impresoras, conexiones de red)

Manejadores de Dispositivos (Drivers)

Son pequeños programas informáticos que sirven como puente lógico entre el sistema operativo y el hardware. Permiten que el sistema controle un componente físico específico sin necesidad de conocer los detalles técnicos exactos de su circuitería interna.


4.2 MECANISMOS Y FUNCIONES DE LOS MANEJADORES DE DISPOSITIVOS

Los manejadores de dispositivos (o drivers) son programas de software que actúan como un puente traductor entre el sistema operativo y el hardware. Su objetivo central es ocultar la complejidad física de los equipos y ofrecer interfaces estandarizadas para que el sistema y las aplicaciones puedan utilizarlos sin conocer sus detalles técnicos.

Funciones Principales

Abstracción de Hardware: Traducen las peticiones abstractas del sistema operativo a instrucciones específicas y de bajo nivel que el componente físico puede procesar.

Manejo de Interrupciones: Gestionan las señales y peticiones (interrupts) que los periféricos envían a la CPU, sincronizando la velocidad del procesador con la de los dispositivos.

Gestión de Errores: Detectan fallos, malfuncionamientos o bloqueos al acceder a los periféricos y ejecutan protocolos para solucionarlos o notificar al sistema operativo.

Administración de Colas: Organizan las solicitudes de entrada/salida (E/S) mediante mecanismos como FIFO (primero en entrar, primero en salir) para regular el flujo de datos.

Mecanismos de Funcionamiento

Interacción con Registros: Envían comandos y leen estados directamente en los registros del controlador físico del dispositivo.

Manejadores de Interrupciones (ISR - Interrupt Service Routines): Bloquean o pausan procesos mientras esperan a que el dispositivo complete una acción (como imprimir un documento) y "despiertan" al procesador cuando la tarea está lista.

Acceso Directo a Memoria (DMA): En dispositivos de alta velocidad, los manejadores configuran el hardware DMA para que transfiera datos directamente entre el periférico y la memoria RAM principal sin sobrecargar la CPU.

Estructura Modular: Se dividen en una parte dependiente del dispositivo (código específico para un modelo y marca) y una independiente del dispositivo (reglas generales que el sistema operativo utiliza para interactuar con categorías de hardware)


4.3 ESTRUCTURAS DE DATOS PARA MANEJO DE DISPOSITIVOS

Las estructuras de datos para el manejo de dispositivos son los componentes del kernel que permiten al sistema operativo comunicarse con el hardware. Actúan como un puente que traduce las peticiones abstractas del usuario en órdenes físicas para los controladores, utilizando buffers, colas y tablas específicas.

Estructuras de Datos

Bloques de Control de Dispositivo (DCB): Estructuras que guardan el estado actual, tipo, dirección de memoria y el propietario de cada dispositivo.

Colas de Solicitud de E/S: Listas enlazadas que almacenan las peticiones pendientes de varios procesos hacia un mismo hardware (ej. el disco duro).

Tablas de Dispositivos: Catálogos mantenidos por el sistema operativo que mapean el nombre lógico del dispositivo con su respectivo controlador (driver).

Buffers y Caches: Bloques de memoria temporal utilizados para nivelar la diferencia de velocidad entre la CPU y los periféricos


4.4 OPERACIONES DE ENTRADA/SALIDA (E/S)

Las operaciones de E/S (Entrada/Salida) son los procesos mediante los cuales un sistema informático se comunica con el mundo exterior. Permiten la transferencia de datos entre el procesador (CPU) o la memoria y los dispositivos periféricos (como teclados, discos duros, impresoras o tarjetas de red).

Técnicas de transferencia

Existen diferentes métodos para realizar estas operaciones dependiendo de la eficiencia y la carga de la CPU:

E/S Programada: El procesador envía la orden y espera en un bucle continuo hasta que el dispositivo termina. Consume mucho tiempo de CPU.

E/S por Interrupciones: El procesador envía la instrucción y continúa ejecutando otras tareas. El periférico envía una señal ("interrupción") cuando está listo.

Acceso Directo a Memoria (DMA): Un controlador especializado transfiere los datos directamente entre el periférico y la memoria principal sin la intervención constante de la CPU.

E/S en Software

A nivel de software y sistemas operativos, la gestión de E/S incluye técnicas para optimizar el rendimiento:

Buffering: Uso de áreas de memoria temporal (búferes) para retener datos mientras se transfieren.

Spooling: Almacenamiento temporal de trabajos (por ejemplo, documentos en cola de impresión) para que los dispositivos más lentos no bloqueen a los procesos más rápidos.
